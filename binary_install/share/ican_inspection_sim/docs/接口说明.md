# 城市应急全域巡检任务一仿真接口

`ican_inspection_sim` 提供 Gazebo 场景、两栖陆空无人机模型、传感器和底层控制话题。

## 启动

```bash
source scripts/setup_env.sh
ros2 launch ican_inspection_sim inspection.launch.py
```

用户工作区推荐使用：

```bash
bash scripts/run_inspection_env.sh
```

## 地面行驶接口

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `/cmd_vel` | `geometry_msgs/msg/Twist` | 地面麦克纳姆轮速度控制，使用 `linear.x`、`linear.y`、`angular.z`。 |
| `/odom` | `nav_msgs/msg/Odometry` | 地面行驶里程计。 |
| `/wheel_speeds` | `std_msgs/msg/Float32MultiArray` | 麦克纳姆四轮角速度。 |
| `/scan` | `sensor_msgs/msg/LaserScan` | 地面二维雷达。 |
| `/camera/image` | `sensor_msgs/msg/Image` | 地面前向相机。 |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 地面相机内参。 |

## 飞行接口

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `/uav/cmd_vel` | `geometry_msgs/msg/Twist` | UAV 飞行速度控制，支持 `linear.x/y/z` 和 `angular.z`。 |
| `/uav/odom` | `nav_msgs/msg/Odometry` | UAV 飞行里程计。 |
| `/uav/camera/image` | `sensor_msgs/msg/Image` | UAV 前向相机。 |
| `/uav/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | UAV 相机内参。 |
| `/uav/lidar/points` | `sensor_msgs/msg/PointCloud2` | UAV 前向 3D 点云。 |
| `/uav/light_on` | `std_msgs/msg/Bool` | 兼容保留的灯光逻辑开关。 |
| `/uav/light_state` | `std_msgs/msg/Bool` | 灯光逻辑状态回传。 |
| `/uav/laser_fire` | `std_msgs/msg/Bool` | UAV 下方激光开关，`true` 发射，`false` 关闭。 |
| `/uav/laser_state` | `std_msgs/msg/Bool` | UAV 下方激光状态回传。 |
| `/uav/laser/scan` | `sensor_msgs/msg/LaserScan` | UAV 下方单线激光测距。 |

UAV 相机、雷达和激光均由 Gazebo Classic 插件发布。用户程序可以直接订阅这些话题并自行实现识别和飞行控制。
